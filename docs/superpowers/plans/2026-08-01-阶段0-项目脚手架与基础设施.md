# 阶段 0：项目脚手架与基础设施 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可运行、可部署的项目地基——monorepo 结构、后端 Spring Boot 骨架、前端 Vite+React+TS+Tailwind 骨架、Docker Compose 本地环境（MySQL + MinIO + 后端）、Flyway 迁移工具接入，使 `docker compose up` 后前端页面能显示"后端已连接"。

**Architecture:** monorepo（根目录下 `backend/`、`frontend/`），后端 Maven + Spring Boot 3.3 暴露 `GET /api/health` 健康检查接口；数据源与 Flyway 迁移在本阶段后半程接入，接入前的基础骨架测试不依赖真实数据库（通过测试环境排除自动配置）；前端在页面加载时请求健康检查接口并展示连接状态；MinIO 仅完成容器部署，本阶段不做业务读写。

**Tech Stack:** Java 17, Spring Boot 3.3.4 (Maven), MySQL 8, Flyway (flyway-mysql), MinIO, React 18 + Vite + TypeScript + Tailwind CSS v4, Vitest + Testing Library, Docker Compose。

## Global Constraints

- 仓库结构固定为 monorepo：根目录 `backend/`、`frontend/`、`docker-compose.yml`、`.env.example`、`.gitignore`、`README.md`
- 后端固定使用 Java 17 + Spring Boot 3.3.4 + Maven（不用 Gradle）
- 前端包管理器固定使用 pnpm（若本机未安装，先执行 `npm install -g pnpm`）
- 数据库结构变更只能通过 Flyway 迁移脚本（`backend/src/main/resources/db/migration/V*.sql`），禁止手工建表
- 本阶段不建任何业务表/接口（Institution/Teacher 等留给阶段 1），只验证基础设施可用
- 单元测试（`mvn test` / `pnpm test`）不得依赖真实数据库或真实 Docker 环境跑通；需要真实基础设施的验证一律走文档化的手动 smoke test 步骤
- 所有服务端口固定：后端 8080，MySQL 3306，MinIO API 9000 / 控制台 9001，前端 dev server 5173

- [ ] **Step 8: 实现 health.ts**

`frontend/src/api/health.ts`

```typescript
export type HealthStatus = 'connected' | 'disconnected'

export async function fetchHealth(): Promise<HealthStatus> {
  try {
    const res = await fetch('/api/health')
    if (!res.ok) {
      return 'disconnected'
    }
    const data = await res.json()
    return data.status === 'ok' ? 'connected' : 'disconnected'
  } catch {
    return 'disconnected'
  }
}
```

# 托管班学生学习管理系统

个人/小团队副业项目。技术栈：React + Vite + TS + Tailwind（前端），Spring Boot + MySQL + MinIO（后端），Docker Compose 编排。

## 本地开发

1. 复制环境变量文件：`cp .env.example .env`
2. 启动后端基础设施（MySQL + MinIO + backend 容器）：
   ```bash
   docker compose up --build -d
   ```
3. 启动前端 dev server（会自动代理 `/api` 到 `http://localhost:8080`）：
   ```bash
   cd frontend
   pnpm install
   pnpm dev
   ```
4. 浏览器打开 `http://localhost:5173`，页面应显示"✅ 后端已连接"

## 常用命令

- 后端测试：`cd backend && mvn test`
- 前端测试：`cd frontend && pnpm vitest run`
- 停止所有容器：`docker compose down`
```
