# 平台机构规模与续费管理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `PLATFORM_ADMIN`（平台管理页）能看到每个机构的规模统计（学生数/班级
数/教师数），并能设置试用到期日、记录续费、维护机构联系方式，到期状态在列表里
用颜色高亮，不做自动锁定/通知推送。

**Architecture:** 后端新增 `institution_renewal_record` 表记录试用/续费历史，
`institution` 表加 `contact_name`/`contact_phone`/`address`/`valid_until` 四
列作为"当前状态"的权威字段（历史表只做审计轨迹，列表查询不聚合历史表）。到期
状态（`NONE`/`ACTIVE`/`EXPIRING_SOON`/`EXPIRED`）是查询时用 `valid_until` 和
当天日期实时算出来的派生值，不落库。前端 `PlatformAdminPage` 的机构列表从简单
`<ul>` 改成表格，新增「续费」「编辑联系信息」两个弹窗。

**Tech Stack:** Spring Boot 3 + MySQL + Flyway（后端），React + TypeScript +
Vitest（前端），`IntegrationTestBase`（Testcontainers）做后端集成测试。

**Spec:** `docs/superpowers/specs/2026-10-11-平台机构规模与续费管理-design.md`

## Global Constraints

- 到期只做后台列表高亮提醒，不自动锁定机构登录，不接短信/邮件/推送通知。
- 到期日由超级管理员每次手动选定一个具体日期；套餐（月/半年/年/试用）只用来
  预填一个建议日期，不做"套餐时长自动算到期日"的隐式计算。
- 试用期和续费共用同一张 `institution_renewal_record` 表、同一个"选套餐 + 选
  日期 + 提交"操作入口，试用期（`plan=TRIAL`）可以在开通机构时设置，也可以之
  后随时再追加一条。
- `classCount` 统计机构下全部 `TeachingUnit`，不拆分托管班/课外课。
- `EXPIRING_SOON` 阈值固定 7 天，写死在后端常量里，不做机构可配置。
- 联系方式（`contactName`/`contactPhone`/`address`）和到期信息只在平台管理视
  角（`PLATFORM_ADMIN`）可见可编辑，不出现在机构自己的管理后台
  （`InstitutionSettingsResponse` 等不受影响）。
- `institutionDao.insert(String name)` 的方法签名和调用方式不能变——现有几十
  个测试文件里都是这样直接造机构数据的，新增字段必须通过新增的 `update*` 方法
  单独设置，不能改 `insert` 的参数列表。

## Review Focus

- 存量机构（`valid_until`/`contact_*` 全是 `NULL`）在状态派生逻辑里必须显示成
  `NONE`，不能被误判成 `EXPIRED`——`NULL` 到期日和"已经过期"是完全不同的语
  义，混淆会让所有老机构在列表里突然变成一片刺眼的红色。
- `EXPIRING_SOON` 的边界要精确：恰好 7 天后到期、8 天后到期、就是今天到期、
  已经过期 1 天，这四种情况要分别落在正确的分支里，日期判断容易出现差一天的
  错误。
- `contactPhone` 必填的校验后端也要用 `@NotBlank` 兜底，不能只在前端表单卡，
  否则绕过前端直接调 API 能插入没有联系电话的机构，到期以后联系不上人。
- `recordRenewal` 的 `amount` 字段在任何套餐下都允许为 `null`（不只是
  `TRIAL`）——早期灵活报价的方向下，超级管理员可能临时不想填金额，不能因为
  `amount` 是 `null` 就报错或者把请求挡在校验层。
- 修改 `Institution` record 字段和 `InstitutionDao` 接口时，必须确认不会破坏
  现有几十个 `institutionDao.insert(name)` 调用点所在的测试套件——这是本次改
  动里最大的"改了一个被广泛依赖的东西"的风险点。

```java
package com.tuoguan.backend.auth.dao;

import com.tuoguan.backend.auth.domain.Institution;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.jdbc.core.RowMapper;
import org.springframework.jdbc.support.GeneratedKeyHolder;
import org.springframework.jdbc.support.KeyHolder;
import org.springframework.stereotype.Repository;

import java.sql.Date;
import java.sql.PreparedStatement;
import java.sql.Statement;
import java.time.LocalDate;
import java.util.List;
import java.util.Optional;

@Repository
public class JdbcInstitutionDao implements InstitutionDao {

    private static final RowMapper<Institution> ROW_MAPPER = (rs, rowNum) -> new Institution(
            rs.getLong("id"),
            rs.getString("name"),
            rs.getString("logo_object_key"),
            rs.getBoolean("custody_enabled"),
            rs.getBoolean("off_campus_enabled"),
            rs.getString("contact_name"),
            rs.getString("contact_phone"),
            rs.getString("address"),
            rs.getDate("valid_until") != null ? rs.getDate("valid_until").toLocalDate() : null,
            rs.getTimestamp("created_at").toInstant());

    private static final String SELECT_COLUMNS =
            "id, name, logo_object_key, custody_enabled, off_campus_enabled, "
                    + "contact_name, contact_phone, address, valid_until, created_at";

    private final JdbcTemplate jdbcTemplate;

    public JdbcInstitutionDao(JdbcTemplate jdbcTemplate) {
        this.jdbcTemplate = jdbcTemplate;
    }

    @Override
    public Long insert(String name) {
        KeyHolder keyHolder = new GeneratedKeyHolder();
        jdbcTemplate.update(connection -> {
            PreparedStatement ps = connection.prepareStatement(
                    "INSERT INTO institution (name) VALUES (?)",
                    Statement.RETURN_GENERATED_KEYS);
            ps.setString(1, name);
            return ps;
        }, keyHolder);
        return keyHolder.getKey().longValue();
    }

    @Override
    public Optional<Institution> findById(Long id) {
        List<Institution> results = jdbcTemplate.query(
                "SELECT " + SELECT_COLUMNS + " FROM institution WHERE id = ?",
                ROW_MAPPER, id);
        return results.stream().findFirst();
    }

    @Override
    public List<Institution> findAll() {
        return jdbcTemplate.query(
                "SELECT " + SELECT_COLUMNS + " FROM institution ORDER BY created_at",
                ROW_MAPPER);
    }

    @Override
    public void updateName(Long id, String name) {
        jdbcTemplate.update("UPDATE institution SET name = ? WHERE id = ?", name, id);
    }

    @Override
    public void updateLogoObjectKey(Long id, String logoObjectKey) {
        jdbcTemplate.update("UPDATE institution SET logo_object_key = ? WHERE id = ?", logoObjectKey, id);
    }

    @Override
    public void updateFeatureFlags(Long id, boolean custodyEnabled, boolean offCampusEnabled) {
        jdbcTemplate.update("UPDATE institution SET custody_enabled = ?, off_campus_enabled = ? WHERE id = ?",
                custodyEnabled, offCampusEnabled, id);
    }

    @Override
    public void updateContact(Long id, String contactName, String contactPhone, String address) {
        jdbcTemplate.update(
                "UPDATE institution SET contact_name = ?, contact_phone = ?, address = ? WHERE id = ?",
                contactName, contactPhone, address, id);
    }

    @Override
    public void updateValidUntil(Long id, LocalDate validUntil) {
        jdbcTemplate.update("UPDATE institution SET valid_until = ? WHERE id = ?",
                validUntil != null ? Date.valueOf(validUntil) : null, id);
    }
}
```

```java
package com.tuoguan.backend.platform.dao;

import com.tuoguan.backend.platform.domain.InstitutionRenewalRecord;
import com.tuoguan.backend.platform.domain.RenewalPlan;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.jdbc.core.RowMapper;
import org.springframework.jdbc.support.GeneratedKeyHolder;
import org.springframework.jdbc.support.KeyHolder;
import org.springframework.stereotype.Repository;

import java.math.BigDecimal;
import java.sql.Date;
import java.sql.PreparedStatement;
import java.sql.Statement;
import java.sql.Types;
import java.time.LocalDate;
import java.util.List;
import java.util.Optional;

@Repository
public class JdbcInstitutionRenewalRecordDao implements InstitutionRenewalRecordDao {

    private static final RowMapper<InstitutionRenewalRecord> ROW_MAPPER = (rs, rowNum) -> new InstitutionRenewalRecord(
            rs.getLong("id"),
            rs.getLong("institution_id"),
            RenewalPlan.valueOf(rs.getString("plan")),
            rs.getBigDecimal("amount"),
            rs.getDate("valid_until").toLocalDate(),
            rs.getString("note"),
            rs.getLong("recorded_by_teacher_id"),
            rs.getTimestamp("created_at").toInstant());

    private static final String SELECT_COLUMNS =
            "id, institution_id, plan, amount, valid_until, note, recorded_by_teacher_id, created_at";

    private final JdbcTemplate jdbcTemplate;

    public JdbcInstitutionRenewalRecordDao(JdbcTemplate jdbcTemplate) {
        this.jdbcTemplate = jdbcTemplate;
    }

    @Override
    public Long insert(Long institutionId, RenewalPlan plan, BigDecimal amount, LocalDate validUntil, String note,
                        Long recordedByTeacherId) {
        KeyHolder keyHolder = new GeneratedKeyHolder();
        jdbcTemplate.update(connection -> {
            PreparedStatement ps = connection.prepareStatement(
                    "INSERT INTO institution_renewal_record "
                            + "(institution_id, plan, amount, valid_until, note, recorded_by_teacher_id) "
                            + "VALUES (?, ?, ?, ?, ?, ?)",
                    Statement.RETURN_GENERATED_KEYS);
            ps.setLong(1, institutionId);
            ps.setString(2, plan.name());
            if (amount != null) {
                ps.setBigDecimal(3, amount);
            } else {
                ps.setNull(3, Types.DECIMAL);
            }
            ps.setDate(4, Date.valueOf(validUntil));
            ps.setString(5, note);
            ps.setLong(6, recordedByTeacherId);
            return ps;
        }, keyHolder);
        return keyHolder.getKey().longValue();
    }

    @Override
    public List<InstitutionRenewalRecord> findAllByInstitutionId(Long institutionId) {
        return jdbcTemplate.query(
                "SELECT " + SELECT_COLUMNS + " FROM institution_renewal_record "
                        + "WHERE institution_id = ? ORDER BY created_at DESC, id DESC",
                ROW_MAPPER, institutionId);
    }

    @Override
    public Optional<InstitutionRenewalRecord> findLatestByInstitutionId(Long institutionId) {
        List<InstitutionRenewalRecord> results = jdbcTemplate.query(
                "SELECT " + SELECT_COLUMNS + " FROM institution_renewal_record "
                        + "WHERE institution_id = ? ORDER BY created_at DESC, id DESC LIMIT 1",
                ROW_MAPPER, institutionId);
        return results.stream().findFirst();
    }
```

```java
    public List<PlatformInstitutionSummary> listInstitutions() {
        return institutionDao.findAll().stream()
                .map(this::toSummary)
                .toList();
    }

    private PlatformInstitutionSummary toSummary(Institution institution) {
        int teacherCount = teacherDao.findAllByInstitutionId(institution.id()).size();
        int studentCount = (int) studentDao.findAllByInstitutionId(institution.id()).stream()
                .filter(Student::enrolled)
                .count();
        int classCount = teachingUnitDao.findAllByInstitutionId(institution.id()).size();
        RenewalPlan currentPlan = renewalRecordDao.findLatestByInstitutionId(institution.id())
                .map(InstitutionRenewalRecord::plan)
                .orElse(null);
        return new PlatformInstitutionSummary(institution.id(), institution.name(), institution.createdAt(),
                teacherCount, studentCount, classCount, institution.contactName(), institution.contactPhone(),
                institution.address(), institution.validUntil(), currentPlan,
                deriveStatus(institution.validUntil()));
    }

    private InstitutionStatus deriveStatus(LocalDate validUntil) {
        if (validUntil == null) {
            return InstitutionStatus.NONE;
        }
        LocalDate today = LocalDate.now();
        if (validUntil.isBefore(today)) {
            return InstitutionStatus.EXPIRED;
        }
        long daysLeft = java.time.temporal.ChronoUnit.DAYS.between(today, validUntil);
        if (daysLeft <= EXPIRING_SOON_THRESHOLD_DAYS) {
            return InstitutionStatus.EXPIRING_SOON;
        }
        return InstitutionStatus.ACTIVE;
    }
```

```tsx
import { useEffect, useState } from 'react'
import { createPortal } from 'react-dom'
import * as platformApi from '../api/platform'

interface RenewalModalProps {
  institutionId: number
  institutionName: string
  currentValidUntil: string | null
  onClose: () => void
  onSaved: () => void
}

const PLAN_LABELS: Record<platformApi.RenewalPlan, string> = {
  TRIAL: '试用',
  MONTHLY: '月',
  HALF_YEAR: '半年',
  YEARLY: '年',
}

const PLAN_DEFAULT_AMOUNT: Record<platformApi.RenewalPlan, string> = {
  TRIAL: '',
  MONTHLY: '299',
  HALF_YEAR: '1499',
  YEARLY: '2899',
}

function todayString(): string {
  return new Date().toISOString().slice(0, 10)
}

function addDays(dateStr: string, days: number): string {
  const d = new Date(dateStr)
  d.setDate(d.getDate() + days)
  return d.toISOString().slice(0, 10)
}

function addMonths(dateStr: string, months: number): string {
  const d = new Date(dateStr)
  d.setMonth(d.getMonth() + months)
  return d.toISOString().slice(0, 10)
}

function baseDateFor(currentValidUntil: string | null): string {
  const today = todayString()
  if (!currentValidUntil) return today
  return currentValidUntil > today ? currentValidUntil : today
}

function suggestValidUntil(plan: platformApi.RenewalPlan, currentValidUntil: string | null): string {
  const base = baseDateFor(currentValidUntil)
  switch (plan) {
    case 'TRIAL':
      return addDays(base, 30)
    case 'MONTHLY':
      return addMonths(base, 1)
    case 'HALF_YEAR':
      return addMonths(base, 6)
    case 'YEARLY':
      return addMonths(base, 12)
  }
}

export function RenewalModal({
  institutionId,
  institutionName,
  currentValidUntil,
  onClose,
  onSaved,
}: RenewalModalProps) {
  const [history, setHistory] = useState<platformApi.RenewalRecord[]>([])
  const [loadingHistory, setLoadingHistory] = useState(true)

  const [plan, setPlan] = useState<platformApi.RenewalPlan>('MONTHLY')
  const [amount, setAmount] = useState(PLAN_DEFAULT_AMOUNT.MONTHLY)
  const [validUntil, setValidUntil] = useState(suggestValidUntil('MONTHLY', currentValidUntil))
  const [note, setNote] = useState('')

  const [saving, setSaving] = useState(false)
  const [saveError, setSaveError] = useState<string | null>(null)

  useEffect(() => {
    platformApi
      .fetchRenewalHistory(institutionId)
      .then(setHistory)
      .finally(() => setLoadingHistory(false))
  }, [institutionId])

  function handlePlanChange(nextPlan: platformApi.RenewalPlan) {
    setPlan(nextPlan)
    setAmount(PLAN_DEFAULT_AMOUNT[nextPlan])
    setValidUntil(suggestValidUntil(nextPlan, currentValidUntil))
  }

  async function handleSubmit() {
    if (!validUntil) return
    setSaving(true)
    setSaveError(null)
    try {
      const parsedAmount = amount.trim() === '' ? null : Number(amount)
      await platformApi.createRenewal(institutionId, plan, parsedAmount, validUntil, note.trim())
      onSaved()
      onClose()
    } catch {
      setSaveError('续费记录失败，请重试')
    } finally {
      setSaving(false)
    }
  }

  return createPortal(
    <div
      className="fixed inset-0 z-50 flex items-center justify-center bg-black/40 p-4"
      onClick={(e) => {
        if (e.target === e.currentTarget) onClose()
      }}
    >
      <div
        className="max-h-[90vh] w-full max-w-lg overflow-y-auto rounded-2xl border border-gray-200 bg-white shadow-xl"
        role="dialog"
        aria-modal="true"
        aria-label="续费"
      >
        <div className="border-b border-gray-100 p-4">
          <h2 className="text-base font-semibold text-gray-800">续费 - {institutionName}</h2>
        </div>

        <div className="space-y-4 p-4">
          <section>
            <h3 className="text-sm font-semibold text-gray-700">历史记录</h3>
            {loadingHistory ? (
              <p className="mt-1 text-xs text-gray-400">加载中...</p>
            ) : (
              <ul className="mt-2 space-y-1 text-xs text-gray-600">
                {history.map((record) => (
                  <li key={record.id}>
                    {PLAN_LABELS[record.plan]} · {record.amount !== null ? `¥${record.amount}` : '—'} · 到期
                    {record.validUntil} · {record.recordedByTeacherName}
                    {record.note && ` · ${record.note}`}
                  </li>
                ))}
                {history.length === 0 && <li>暂无记录</li>}
              </ul>
            )}
          </section>

          <section className="flex flex-wrap items-end gap-2">
            <label className="flex flex-col text-xs text-gray-500">
              套餐
              <select
                aria-label="套餐"
                value={plan}
                onChange={(e) => handlePlanChange(e.target.value as platformApi.RenewalPlan)}
                className="rounded border px-2 py-1 text-sm text-gray-900"
              >
                <option value="TRIAL">试用</option>
                <option value="MONTHLY">月</option>
                <option value="HALF_YEAR">半年</option>
                <option value="YEARLY">年</option>
              </select>
            </label>
            <label className="flex flex-col text-xs text-gray-500">
              金额
              <input
                aria-label="金额"
                type="number"
                value={amount}
                disabled={plan === 'TRIAL'}
                onChange={(e) => setAmount(e.target.value)}
                className="w-24 rounded border px-2 py-1 text-sm text-gray-900 disabled:opacity-50"
              />
            </label>
            <label className="flex flex-col text-xs text-gray-500">
              新的到期日
              <input
                aria-label="新的到期日"
                type="date"
                value={validUntil}
                onChange={(e) => setValidUntil(e.target.value)}
                className="rounded border px-2 py-1 text-sm text-gray-900"
              />
            </label>
            <label className="flex flex-1 flex-col text-xs text-gray-500">
              备注（选填）
              <input
                aria-label="备注（选填）"
                value={note}
                onChange={(e) => setNote(e.target.value)}
                className="rounded border px-2 py-1 text-sm text-gray-900"
              />
            </label>
          </section>

          {saveError && <p className="text-sm text-red-600">{saveError}</p>}
        </div>

        <div className="flex justify-end gap-2 border-t border-gray-100 p-3">
          <button
            type="button"
            onClick={onClose}
            disabled={saving}
            className="rounded-full border border-gray-200 px-3 py-1 text-sm text-gray-600 disabled:opacity-50"
          >
            取消
          </button>
          <button
            type="button"
            onClick={handleSubmit}
            disabled={saving || !validUntil}
            className="rounded-full bg-blue-600 px-3 py-1 text-sm font-medium text-white disabled:opacity-50"
          >
            {saving ? '提交中...' : '提交'}
          </button>
        </div>
      </div>
    </div>,
    document.body,
  )
}
```

- [ ] **Step 3: 写 `EditInstitutionContactModal.tsx`**

```tsx
import { useState } from 'react'
import { createPortal } from 'react-dom'
import * as platformApi from '../api/platform'

interface EditInstitutionContactModalProps {
  institutionId: number
  institutionName: string
  initialContactName: string | null
  initialContactPhone: string | null
  initialAddress: string | null
  onClose: () => void
  onSaved: () => void
}

export function EditInstitutionContactModal({
  institutionId,
  institutionName,
  initialContactName,
  initialContactPhone,
  initialAddress,
  onClose,
  onSaved,
}: EditInstitutionContactModalProps) {
  const [contactName, setContactName] = useState(initialContactName ?? '')
  const [contactPhone, setContactPhone] = useState(initialContactPhone ?? '')
  const [address, setAddress] = useState(initialAddress ?? '')
  const [saving, setSaving] = useState(false)
  const [saveError, setSaveError] = useState<string | null>(null)

  async function handleSubmit() {
    setSaving(true)
    setSaveError(null)
    try {
      await platformApi.updateInstitutionContact(institutionId, contactName.trim(), contactPhone.trim(), address.trim())
      onSaved()
      onClose()
    } catch {
      setSaveError('保存失败，请重试')
    } finally {
      setSaving(false)
    }
  }

  return createPortal(
    <div
      className="fixed inset-0 z-50 flex items-center justify-center bg-black/40 p-4"
      onClick={(e) => {
        if (e.target === e.currentTarget) onClose()
      }}
    >
      <div
        className="w-full max-w-sm rounded-2xl border border-gray-200 bg-white shadow-xl"
        role="dialog"
        aria-modal="true"
        aria-label="编辑联系信息"
      >
        <div className="border-b border-gray-100 p-4">
          <h2 className="text-base font-semibold text-gray-800">编辑联系信息 - {institutionName}</h2>
        </div>

        <div className="space-y-3 p-4">
          <label className="flex flex-col text-xs text-gray-500">
            联系人姓名
            <input
              aria-label="联系人姓名"
              value={contactName}
              onChange={(e) => setContactName(e.target.value)}
              className="mt-1 rounded border px-2 py-1 text-sm text-gray-900"
            />
          </label>
          <label className="flex flex-col text-xs text-gray-500">
            联系电话
            <input
              aria-label="联系电话"
              value={contactPhone}
              onChange={(e) => setContactPhone(e.target.value)}
              className="mt-1 rounded border px-2 py-1 text-sm text-gray-900"
            />
          </label>
          <label className="flex flex-col text-xs text-gray-500">
            地址
            <input
              aria-label="地址"
              value={address}
              onChange={(e) => setAddress(e.target.value)}
              className="mt-1 rounded border px-2 py-1 text-sm text-gray-900"
            />
          </label>
          {saveError && <p className="text-sm text-red-600">{saveError}</p>}
        </div>

        <div className="flex justify-end gap-2 border-t border-gray-100 p-3">
          <button
            type="button"
            onClick={onClose}
            disabled={saving}
            className="rounded-full border border-gray-200 px-3 py-1 text-sm text-gray-600 disabled:opacity-50"
          >
            取消
          </button>
          <button
            type="button"
            onClick={handleSubmit}
            disabled={saving}
            className="rounded-full bg-blue-600 px-3 py-1 text-sm font-medium text-white disabled:opacity-50"
          >
            {saving ? '保存中...' : '保存'}
          </button>
        </div>
      </div>
    </div>,
    document.body,
  )
}
```
