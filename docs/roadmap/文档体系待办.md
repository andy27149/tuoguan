## 决策记录（供以后参考）

- 培训文档选择 HTML（本地静态文件）而不是 Artifact 或仓库外链接——用户没有 Artifact 账号，且这类文件主要靠手机打开看，本地文件更直接；招商材料额外做了一份真实 `.pptx`（而不是用 HTML 伪装成幻灯片），面向线下讲稿场景。
- 代码架构索引没有手写静态类清单，而是用 `codebase-memory-mcp` 的图谱索引——理由是静态文档会随重构过时，图谱可以重新索引保持当前，索引产物体积不大（1.6MB）已提交到 git 方便团队/其他会话复用。
- 核实过程中发现并修正了 3 处此前文档里的过期/错误理解（托管学生不能充值课外课、对账单按钮仅纯课外课学生可见、教师可自建班级），这些修正已经同步到业务架构/流程文档、培训手册、产品诊断文档的所有相关位置——这类"理解有误"的反馈比"内容过期"更值得警惕，因为它们会让使用文档的人做出错误判断，不只是信息滞后。
