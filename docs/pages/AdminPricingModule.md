# AdminPricingModule

**文件**：`frontend/src/pages/AdminPricingModule.tsx`
**角色**：`ADMIN`

## 一句话

全机构定价的统一入口——托管学费/餐费 + 课外课单价，都在这一页管理（2026-10-03 之前课外课单价曾错放在教学单元管理页，已统一迁到这里，见[诊断 #04](../功能全景与产品诊断.md)）。

## 功能点

- **托管班级定价**：
  - 按班级单独设置学费（元/月）+ 餐费（元/天）
  - 「批量设置所有班级定价」：一次性把统一的学费/餐费套用到全部托管班（会覆盖已经单独设置过的班级，需二次确认）
  - 没设置过单价的班级显示"未配置"，不代表没有历史账单（已生成的账单是按生成当时的单价快照的，之后改价不会倒算）
- **课外课定价**：列出全部课外课程，可编辑单价，没配置的显示"未配置"（同样不影响该课程已有的历史账单）
- 页面上有提示引导去「费用管理」弹窗核对实际生效的金额（账单里的金额也可能是手动录入覆盖过的，定价中心看到的是默认单价，不一定等于某笔具体账单的最终金额）

## 依赖

- `api/billing.ts`（托管定价读写）、`api/unit.ts`（课外课单价读写）
- `components/ConfirmDialog.tsx`、`components/Toast.tsx`
