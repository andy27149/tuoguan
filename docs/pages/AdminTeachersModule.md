# AdminTeachersModule

**文件**：`frontend/src/pages/AdminTeachersModule.tsx`
**角色**：`ADMIN`

## 一句话

机构内教师账号的增删改——建号、改名、删除（删除前会先评估影响范围）。

## 功能点

- **教师列表**：手机号、教师姓名、角色（教师/管理员）、账号状态（已启用/待修改初始密码）、操作列
- **新增教师**：填手机号、姓名、初始密码，单选角色（`TEACHER`/`ADMIN`，`newTeacherRole`），创建成功后初始密码明文展示一次（"此密码仅显示一次，请尽快告知该教师"）；手机号已被注册会报错
- **编辑教师**：改名（不含改手机号/密码，密码重置由另一条路径处理——见下）
- **删除教师**：点击后先调用接口获取"删除影响范围"（`DeleteTeacherModal.tsx`）——如果该教师名下有班级/任务库模板，弹窗会展示具体数量，并要求选择处理方式：「删除全部」（班级、任务库模板、学生记录一并清除，不可恢复）或「转移给其他老师」（选目标老师，班级与任务库整体转移，学生保留）；只有在没有其他老师可转移时才默认选中"删除全部"，否则默认选中更安全的"转移"选项。这是不可逆的高风险操作
- 点击某个教师能看到"管理班级"信息，可跳转查看该教师名下班级的只读看板（对应 [KanbanPage.md](./KanbanPage.md) 的管理员只读分支）

## 依赖

- `api/admin.ts`、`api/client.ts`（`ApiError`，识别手机号冲突 409）
- `components/DeleteTeacherModal.tsx`
