# AdminTeachingUnitsModule

**文件**：`frontend/src/pages/AdminTeachingUnitsModule.tsx`
**角色**：`ADMIN`

## 一句话

托管班和课外课的统一管理页——建单元、改派老师、改名、启停、删除，全部收归管理员，教师没有自建入口。

## 功能点

- **列表**：按类型（托管班/课外课）分 Tab 或分区展示，每行显示名称、负责教师、（课外课）时长、单价、状态
- **新建**：填名称 + 指定负责教师；课外课额外要填时长，单价可留空（之后在"定价中心"补，或点"前往定价中心设置"直接跳转）；同一教师下不能有同名班级/课程
  - 创建时会校验机构的功能开关——如果对应业务（托管/课外课）没开，会报错提示"该功能未开启，请先在基础配置中开启"（注意：这是**创建环节**的校验，不是对已有数据的全面拦截，见[诊断 #07](../功能全景与产品诊断.md)）
- **编辑**：改名称、改派负责教师、（课外课）改时长/单价
- **停用 / 启用**：`ConfirmDialog` 二次确认——停用会立刻影响教师端与家长端的可见性（"相关入口"消失），已产生的记录不会被删除，可随时重新启用（"重新启用是安全的加法操作"）
- **删除**：二次确认，明确提示"该教学单元下有 N 名学生，删除后相关记录将全部清空且不可恢复"

## 依赖

- `api/unit.ts`（`fetchTeachingUnits`/`createTeachingUnit`/等）、`api/admin.ts`（教师列表供选择负责人）
- `api/client.ts`：`ApiError`（识别功能未开启等业务错误）
- `components/ConfirmDialog.tsx`、`components/Toast.tsx`
