# AdminBillingModule

**文件**：`frontend/src/pages/AdminBillingModule.tsx`
**角色**：`ADMIN`（托管功能关闭时模块入口隐藏，但纯课外课学生的账单仍然可以通过"只看纯课外课学生"筛选查看）

## 一句话

月度账单的生成、核对、收款标记——机构每月回款的核心工作台。

## 功能点

- **筛选**：按班级（含"全部班级"和"只看纯课外课学生"两个特殊选项）、按月份（留空查看全部月份）、按学生姓名搜索
- **排序**（2026-10-13 新增，产品诊断 #14）：默认排序 / 逾期天数优先 / 金额优先，前端对已拿到的行排序，未生成账单的行始终排在末尾
- **学生账单列表**：每行显示学生姓名、班级、托管教师、（不按月份筛选时还会多一列）月份、是否已缴费（已缴费时附带收款方式）、逾期天数、账单金额、费用管理入口
- **生成账单**：
  - 单个：针对某个学生/班级+月份生成
  - 「一键生成本月账单」：范围是**当前筛选结果**（2026-10-13 调整，产品诊断 #55）——按班级筛了、按姓名搜了，就只对列表里当前展示的这些学生批量生成，不筛选就等于全机构（含纯课外课学生）当月所有在读学生；已生成过的会被重新计算覆盖，因班级未配置单价而失败的学生会被跳过并在结果弹窗（`RollCallResultModal.tsx`）里列出原因，不影响其他学生。筛选结果为空时点击按钮不会弹确认框，只提示"当前无学生可以生成账单！"（Toast）
- **标记已缴费 / 未缴费**：点击切换，均有二次确认（`ConfirmDialog`）；标记为已缴费时必须先从下拉选择收款方式（现金/微信/支付宝/银行转账），标记为未缴费不需要选择、会清空已记录的收款方式（2026-10-13 新增，产品诊断 #14）
- **逾期天数**：未缴费账单显示距离到期日（约定为账单所属月份月底）已过去的天数，已缴费或刚生成未逾期则显示"—"
- **账单详情**（`components/BillDetailModal.tsx`）：展开看学费/餐费/请假扣减/课外课附加费各项明细
- **费用管理**（`components/FeeManagementModal.tsx`）：手动调整/录入某笔费用（和定价中心的"默认单价"是两回事，这里是具体某个学生某个月的实际生效金额）

**已评估但未采用/已回退的方案**：曾短暂上线过"批量勾选+批量标记已缴费"功能（配合全选 checkbox），但发现页面同时存在「一键生成本月账单」按钮、勾选框只对批量标记生效而对生成账单无效，容易让人误以为两个按钮都受勾选影响，造成误解。2026-10-13 已从前端临时移除批量标记功能和对应 checkbox（后端接口 `PATCH /admin/bills/batch-paid` 保留未删），待真实使用中出现明确需求后再重新设计统一的交互。部分收款登记（按金额拆分多次收款）目前也不支持，仍是已知缺口，见 [功能全景与产品诊断.md #14](../功能全景与产品诊断.md)。
